サーバ物理補助（足元Y）

プレイヤー位置のYはスポーンと同じく足元基準。床抜け時にサーバがこの範囲へクランプします（多層マップではvoid用の下限のみ想定）。

スポーンYと下限が大きく離れています。意図を確認してください。

Prefab LOD（距離）

prefabManifest 付きモデルのみ。境界はプレイヤー描画距離（m）に対する倍率（例: 1.0 = 100%）。スライダーは最大 500% まで。

飛行機の操縦パラメータ・コックピット／追従カメラは飛行機タブの機体ライブラリで機体 ID ごとに設定します。ワールド編集のオブジェクトではライブラリ ID のリンクのみ行ってください。

worlds.json を編集

表示内容は「JSONでエクスポート」と同じく、現在の編集状態を反映します。保存でサーバーの worlds.json に書き込みます。

ファイルを管理

サーバー上のアセットフォルダを参照します。チェックボックスで複数選択できます。Shift+クリックでその間のファイルをまとめて選択できます（フォルダは削除できません）。

    ファイルのアップロード

    種類

    GLB はサーバでテクスチャの縦横を指定の上限まで縮小してから保存します（長辺・短辺それぞれが上限、縦横比は維持。複数アップロード時はサーバ側で順番に処理）。下のチェックで縮小を省略できます。

    PDF をサーバーにアップロードします。同名ファイルがある場合は上書きの確認が表示されます。

    Radiance の .hdr のみ。default.hdr として保存され、メタバースは /env/default.hdr から読み込みます。

    ZIP 内の複数 GLB と同梱アセットを展開し、*-prefab-manifest.json とともに models/ 配下に保存します。一部のファイル名が既にある場合は一覧で上書き確認できます。
